# VS Code에서 Jupyter Notebook 실행


### 웹크롤링이 필요한 이유
1) 데이터 분석 과정
2) 웹사이트 자동화
3) 인공지능 학습 데이터

### 데이터 분석

1. 분석 설계
> - 방향성 기획
> - 주제 정의
> - 가설 설정

2. 데이터 수집
> - 웹크롤링
> - API
> - 파일데이터(json, csv)

3. 데이터 가공
> - 원하는 형태로 데이터 수정
> - 데이터 전처리

4. 데이터 분석
> - 통계 분석
> - 데이터 시각화 (그래프, 표)

5. 결론 도출
> - 분석 결과 해석

### 웹크롤링 주요 활용 사례
- 상품, 컨텐츠 자동 업로드
- 부동산 주식 재테크 데이터 수집
- 인스타그램, 유튜브 모니터링 및 분석
- 뉴스 데이터 수집
- 논문, 구인공고 데이터 수집

### 환경설정
- VS Code 확장자 > `Live Server` 설치 
- Live Server > Setting : Custom Browser 에서 null을 `chrome` 으로 변경
